Unit 1 — Introduction & Problem Setup
Q.01Define analytics and predictive analytics.2 marks
Analytics is the discovery, interpretation and communication of patterns in data to improve decisions. Predictive analytics is a collection of statistical/ML techniques that use historical data to estimate unknown future outcomes so humans or machines can make better decisions.
Q.02How does Business Intelligence (BI) differ from Predictive Analytics?2 marks
BI is retrospective — it analyzes historical/current data via reports, dashboards and KPIs to answer “what happened?”. PA is prospective — it uses historical data to predict future behaviour, answering “what is likely to happen?”.
Q.03List the four types of analytics.2 marks
Descriptive (what is happening), Diagnostic (why it happened), Predictive (what will happen), Prescriptive (what action to take).
Q.04What is CRISP-DM? Name its six phases.2 marks
Cross-Industry Standard Process for Data Mining — a six-phase iterative process model: Business Understanding, Data Understanding, Data Preparation, Modeling, Evaluation, Deployment, connected by feedback loops.
Q.05What is the “three-legged stool” of business understanding?2 marks
The three expert groups a PA project needs to succeed: Domain experts, Data/Database experts, and Predictive modeling experts. If any one is missing, the project is at risk of failure.
Q.06Define data leakage with one example.2 marks
Using information in training data that would not actually be available at prediction time. Eg: using “has phone number” to predict “became customer”, when the phone number was only collected after conversion.
Q.07What is the unit of analysis?2 marks
What each row/record in the modeling dataset represents (one customer, one visit, one transaction). Predictive algorithms assume every record is an independent observation.
Q.08List the three types of target variables.2 marks
Binary (two outcomes, eg churn Yes/No), Continuous (numeric value, eg future spend), Categorical (multiple classes, eg fraud type 1/2/3/none).
Q.09What is a “time gap” in target variable definition, and why is it needed?2 marks
The interval kept between the data used for prediction and the event being predicted, so the business has time to act before the event happens — eg predicting churn 30 days ahead instead of on the day it occurs.
Q.10Define overfitting.2 marks
When a model becomes too complex and memorizes the training data instead of learning general patterns — it performs very well on training data but poorly on new/unseen data.
Q.11What is PCC?2 marks
Percent Correct Classification — overall classification accuracy computed from the confusion matrix; treats every kind of error with equal weight.
Q.12Name four metrics used for continuous-valued estimation (regression) problems.2 marks
R² (R-squared), Mean Squared Error (MSE), average/mean absolute error (MAE), median error / median absolute error.

Q.02Explain the CRISP-DM Process Model5 marks

The Cross-Industry Standard Process for Data Mining (CRISP-DM) describes six steps for building predictive models, connected by feedback loops so the project can revisit earlier stages.

CRISP-DM Cycle

After defining business objectives, the data understanding phase analyzes what data is actually available. If the data is insufficient or poor quality, the project may need to loop back and redefine the objectives. If a built model gives low accuracy, the project loops back to data preparation to create new derived features. This iteration continues until results are good enough to deploy.

Q.03Explain the Obstacles That Cause Predictive Analytics Projects to Fail10 marks

Predictive models often fail in real-world operations for four broad categories of reasons.

1. Obstacles in Management

Problems related to people, planning and business support: the problem is not clearly defined, there is no support from decision-makers, or predictions are simply not used in business decisions. Eg: a fraud detection model flags 1,000 suspicious transactions a month, but without investigator trust and management support, the flags are never acted on.

2. Obstacles with Data

Predictive models need data in a single rectangular table (rows × columns). Real data is usually spread across multiple transactional databases and must share a common key to be joined.

  • Different tables: if the customer table doesn’t record which campaign created the customer, you cannot tell who responded and who ignored the offer — training data cannot be built.
  • History removed: updating a lead’s record when they become a customer overwrites the old values, destroying the “before” snapshot the model needs.
  • Data leakage: using information (like a phone number) that was only obtained after the outcome occurred.

3. Obstacles with Modelling

Overfitting — the model memorizes training data and performs poorly on unseen data; this may only be discovered after deployment. Overly ambitious models — analysts try to build an advanced model without considering available data, time or budget; a better approach is a simple working model first, improved later with more data, features, or advanced algorithms.

4. Obstacles with Deployment

A model that works well in development can still fail at deployment: it must be translated into the language the production system supports (SQL, Java, C++), and the exact same data preparation steps used during training must be repeated in real time — which can be too slow for use cases like on-page content recommendation that must respond within seconds.

Q.05Explain the Three Methods of Defining Columns as Measures for Repeated Events5 marks

When a unit of analysis (eg a customer) has a variable number of repeated events (eg hotel visits), a single rectangular row still has to represent them. Three methods are used:

Method 1 — Separate columns per visit

Store Visit 1, Visit 2, Visit 3… as separate columns. Problem: customers with fewer visits get NULL/missing values, and many algorithms handle missing values poorly.

Method 2 — Most recent visit first

Customer IDRecent VisitPrevious Visit
1000015/2/12NULL
10000210/13/129/29/12

Advantage: captures the most recent, often most predictive, behaviour.

Method 3 — Summarize into derived features

Instead of storing each visit, create features like total visits, average spend, days since last visit. Advantages: no missing values, stays rectangular, easiest for models to use. This is the generally preferred approach.

Q.06Explain Unit of Analysis with the Hotel Booking Example5 marks

The unit of analysis defines what each row represents, and predictive algorithms assume every record is independent. If records are actually connected, the model learns biased patterns.

Correct case

A hotel wants to predict “will this customer book again?” Unit of analysis = one customer. Each row is independent: customer 101, 102, 103… The model learns general patterns like “frequent visits → higher chance of returning”.

Customer IDVisitsPurposeBook Again
1015VacationYes
1021BusinessNo
1033Family TripYes

Biased case

If all customers in the training data are employees of the same company, their behaviour is connected — same travel policy, same location preference. The model ends up learning “ABC company travel rules” instead of general customer behaviour. When a genuine family-vacation customer is scored after deployment, the prediction is wrong because the model never saw a real independent customer during training.

Rule: always check whether records could be influenced by a shared factor (same company, same household, same time window) before treating them as independent.

Temporal considerations — the time gap

A time gap must be kept between the data used for prediction and the event being predicted, so there is time to act. Without a gap, a churn model that fires the day the customer leaves is useless — the company cannot intervene. With a gap, the model predicts “may leave in 30 days” using Jan–March activity, giving the company time to offer discounts or improve service before the customer actually leaves.

Measures of success — classification

PCC (Percent Correct Classification) measures overall accuracy, weighting every error equally. The confusion matrix breaks errors down into false alarms and false dismissals and is good for judging the whole population. When only a selected subset of the population will actually be treated (eg only the top-scored leads get a sales call), Lift, Gain, ROC, and AUC are used instead, since they measure how well the model ranks a subset.

Measures of success — estimation

For continuous targets: R², average error, MSE, median error, average/median absolute error. Average error reveals whether the model is biased positive or negative; absolute error metrics reveal the magnitude of errors regardless of direction.

The model runs directly on a device rather than a server — no network round-trip. Eg: face detection running locally on a CCTV camera or an IoT sensor.

Q.01Explain the Prediction Effect with the Prediction–Decision–Action Cycle5 marks

The prediction effect describes how using predictions in decision-making changes real-world outcomes. A prediction is rarely the end of the story — it triggers a decision, which triggers an action, which changes the actual outcome, which becomes new data for the next cycle.

Prediction Effect Cycle

Positive effect example: a university predicts a student is likely to fail, provides extra coaching, and the student passes — the prediction led to a good outcome. Negative effect example: a bank predicts a customer is likely to default and rejects every such application; if the customer can’t get credit elsewhere, their financial situation worsens — the decision made from the prediction actively harmed the outcome.

This matters because PA should be judged not only on prediction accuracy, but on its real-world impact once decisions are actually made from it.

Q.02Why Is It Hard to Judge a Prediction’s Correctness When the Predicted Event Is Prevented?5 marks

When a prediction triggers a preventive action, the predicted event may never occur — making it impossible to know for certain whether the prediction was actually correct.

ScenarioPredictionAction takenResult
CybersecurityIP address likely to attackIP blockedAttack never happens — was the prediction right?
HospitalPatient high risk of diseaseExtra tests, monitoring, preventive treatmentPatient stays healthy — model isn’t “wrong”, intervention worked

The sequence Prediction → Preventive Intervention → Risk Reduced → Expected Event Does Not Occur means the absence of the predicted event is not proof the model was wrong — it may be proof the intervention worked. This is a key nuance examiners like to test.

Unit 3 — Decision Trees
Q.01What is a decision tree used for? Name two ensemble algorithms built on it.2 marks
Used for both classification and regression. Ensemble algorithms like Random Forest and XGBoost combine multiple decision trees to improve accuracy and reduce overfitting.
Q.02Define a pure node.2 marks
A node where all records belong to a single class (eg 100% play cricket, 0% don’t). The objective of a decision tree is to reach nodes as pure as possible. A pure node has Gini Impurity = 0.
Q.03Write the formula for Gini and Gini Impurity.2 marks
Gini = Σ pi2 (sum of squared class probabilities). Gini Impurity = 1 − Gini = 1 − Σ pi2. Value ranges 0–1; lower means purer. Pick the split with the lowest weighted Gini Impurity.
Q.04What does CHAID stand for, and what test does it use?2 marks
Chi-square Automatic Interaction Detection. It selects the feature with the strongest statistical association to the target using the Chi-square test — the variable with the least p-value (highest χ² value) is chosen for splitting.
Q.05What splitting technique is used for a continuous target variable?2 marks
Reduction in variance (used by CART). The split whose children give the lowest weighted average variance is selected — used for continuous targets like taxi fare or sales amount.
Q.06Write the variance formula used in reduction-in-variance splitting.2 marks
Variance = Σ(X − μ)² / n, where X is each data value, μ is the mean of the node, and n is the number of observations in that node.
Q.07What happens if no constraint is placed on tree growth?2 marks
The tree grows until every node is pure, fitting the training data at ~100% accuracy — but this causes overfitting: the model memorizes training observations and performs poorly on unseen data.
Q.08Name the four hyperparameters used to control overfitting/underfitting in a DT.2 marks
Minimum samples for a node split, minimum samples for a terminal (leaf) node, maximum depth of the tree, maximum number of terminal nodes.
Q.09What is the effect of setting “minimum samples per split” too high?2 marks
Higher values control overfitting, but too high a value causes underfitting — the model can’t split enough to learn anything useful from the data.
Q.10What is the effect of setting max_depth too low, eg depth = 1?2 marks
The tree can barely split, so training accuracy itself is poor — this causes underfitting. Too high a depth instead causes overfitting. The correct depth is tuned using validation data.

Q.01Explain Gini Impurity as a Splitting Criterion, Worked with the Play Cricket Dataset10 marks

Gini Impurity measures how mixed a node is. For a node with class probabilities p1, p2…, Gini = Σpi2 and Gini Impurity = 1 − Gini. A pure node has Gini Impurity = 0; a 50/50 split has the maximum impurity of 0.5. A decision tree evaluates every candidate feature, computes the weighted Gini Impurity of the resulting children, and picks the split with the lowest weighted impurity.

Steps for developing a CHAID tree

  1. Start with the complete training data at the root node.
  2. Check the statistical significance (Chi-square) of every independent variable.
  3. The variable with the least p-value (highest χ²) is used to split, creating subsets.
  4. Repeat step 3 on each subset until variables are exhausted or not significant at α, or a stopping criterion is met.
  5. Generate business rules for the terminal (leaf) nodes.

Q.04Explain the Hyperparameters Used to Optimize Decision Tree Performance10 marks

An unconstrained tree grows until every leaf is pure, memorizing the training data (100% training accuracy) but overfitting and generalizing poorly. Four hyperparameters balance overfitting against underfitting:

HyperparameterHigher value effectToo-high value risk
Min. samples for a node splitControls overfitting — forces more data before any splitUnderfitting — model doesn’t learn enough patterns
Min. samples for a terminal (leaf) nodeControls overfitting — leaf must hold at least this many recordsUnderfitting — can’t split even from the root; parent node becomes leaf
Maximum depth of treeHigher depth → more splits → overfitting riskLower depth → underfitting (depth = 1 barely learns anything)
Maximum number of terminal nodesMore nodes → finer partitions → overfitting riskFewer nodes → underfitting

Setting depth = 1 is the classic underfitting example: the training data itself isn’t modeled well enough to even check accuracy properly. The correct setting is tuned using validation data to sit between the two failure modes — not too deep and not too shallow.

Unit 3.7 — Convolutional Neural Networks
Q.01Why doesn’t a plain ANN work well directly on images?2 marks
A plain feed-forward ANN needs a flat 1D input vector, so an image would have to be flattened immediately, destroying spatial structure (which pixels are near which). CNNs slide small filters over the 2D/3D image to preserve and exploit that structure before flattening.
Q.02Define a filter / kernel in a CNN.2 marks
A small matrix (eg 3×3, 5×5) of learnable weights that slides across the input, computing an element-wise multiply-and-sum at each position to produce one value in the output feature map.
Q.03Write the formula for output size after convolution.2 marks
n′ = ⌊(n − f + 2p) / s⌋ + 1, where n = input size, f = filter size, p = padding, s = stride.
Q.04Differentiate “valid” and “same” padding.2 marks
Valid: p = 0, no padding, output shrinks every layer. Same: p = (f−1)/2, chosen so output size equals input size — border pixels are padded with zeros.
Q.05What does stride control?2 marks
How many pixels the filter shifts each step. Stride 1 moves one pixel at a time; stride 2 skips positions and roughly halves the output size, downsampling the feature map.
Q.06What is the purpose of a pooling layer? Does it have learnable parameters?2 marks
Pooling downsamples height/width (keeping channels unchanged) to reduce computation and add tolerance to small spatial shifts. It has no learnable weights — nothing in a pooling layer is updated during backpropagation.
Q.07Differentiate softmax and sigmoid as output activations.2 marks
Sigmoid: one output node, value 0–1, used for binary classification. Softmax: one node per class, all outputs sum to 1, used for multi-class classification.
Q.08Why aren’t pooling-layer weights updated during backpropagation?2 marks
Because a pooling layer has no weights or biases to begin with — it just takes a max or average of a region. Only convolution filter weights and biases (and FC layer weights) are updated during training.
Q.09Write the cross-entropy loss formula.2 marks
L = −Σ yi log(ŷi), where y is the one-hot true label vector and ŷ is the predicted probability vector from softmax.
Q.10Write the gradient descent weight-update rule.2 marks
wnew = wold − α · ∂L/∂w (and similarly for bias b), where α is the learning rate.
Q.01Explain the CNN Architecture, Layer by Layer10 marks

A CNN is built on the same feed-forward idea as an ANN, with a front end designed for spatial data. Convolution and pooling layers repeat to extract features; the result is flattened and passed to fully connected layers for classification.

CNN Pipeline
LayerFunction
ConvolutionSlides learnable filters over the input; each filter detects one pattern (edge, texture, shape)
ReLUZeros out negative values in the feature map (introduces non-linearity)

Q.02Explain the Convolution Operation with Padding and Stride — Worked Example10 marks

At each filter position, multiply every filter cell by the image cell beneath it and sum the results — that single number becomes one entry of the output feature map. The filter then slides by the stride amount and repeats.

Output size formula: n′ = ⌊(n − f + 2p)/s⌋ + 1

Input nFilter fPadding pStride sCalculationOutput n′
630 (valid)1(6−3+0)/1 + 1 = 44×4
6302⌊(6−3+0)/2⌋ + 1 = ⌊1.5⌋+12×2
631 (same)1(6−3+2)/1 + 1 = 66×6

Same padding is derived by setting n′ = n and solving: p = (f−1)/2. For f = 3, p = 1; for f = 5, p = 2. Padding matters because without it, edge and corner pixels participate in far fewer convolutions than centre pixels, under-representing image borders.

Q.03Explain Multi-Channel Convolution (RGB Images, Multiple Filters)5 marks

A colour image is 3D: height × width × 3 channels (R, G, B). The filter must match that depth — a “3×3 filter” on an RGB image is really 3×3×3. Each channel is convolved separately and the three results are summed into a single 2D output value per position — so a 3D input convolved with one 3D filter always collapses to a 2D map (eg 6×6×3 ⊛ 3×3×3 → 4×4 single-channel map).

One filter only detects one pattern. To detect several patterns simultaneously, a layer uses multiple filters, each producing its own 2D map; these maps stack to form the depth of the next layer. Eg: two 3×3×3 filters on a 6×6×3 image each give a 4×4 map, stacking into a 4×4×2 volume. The number of filters in a layer becomes the number of channels in the next layer. A bias is added per filter, then ReLU is applied element-wise.

Q.04Explain Pooling (Max vs Average) with a Worked Example5 marks

Pooling slides a small window (commonly 2×2, stride 2) over each channel of the feature map independently, taking either the maximum or average value in the window. Channels stay the same; only height and width shrink.

Input (4×4)Max pool, f=2, s=2
4 9 2 5 5 6 2 4 2 4 5 4 5 6 8 49 5 6 8

Why pool: (1) reduces computation and memory for later layers, (2) keeps the strongest activation in a region while discarding exact pixel position — giving tolerance to small translations, (3) has zero learnable weights, so pooling layers are completely skipped during backpropagation weight updates. Unlike conv layers, pooling does not learn to detect features; it simply downsamples what convolution already extracted.

Q.05Explain Loss Computation and Backpropagation in a CNN10 marks

Loss functions

LossFormulaUse
L1 (MAE)|y − ŷ|Regression, robust to outliers
L2 (MSE)(y − ŷ)²Regression, penalizes large errors more heavily
Cross-entropy−Σ yi log(ŷi)Classification, paired with softmax output

Softmax

Converts raw logits zi into class probabilities: ŷi = ezi / Σk ezk. The true label y is one-hot encoded (eg [0,0,1,0] for class 3 of 4) before computing cross-entropy loss.

Backpropagation

The loss is backpropagated to find ∂L/∂w and ∂L/∂b for every learnable weight and bias, then gradient descent updates them:

w_new = w_old - α · ∂L/∂w b_new = b_old - α · ∂L/∂b

α is the learning rate. This updates convolution filter weights, filter biases, and fully-connected layer weights. Pooling layers have no weights, so nothing in them is touched during backpropagation — a favourite short-answer trap question.
